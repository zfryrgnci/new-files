# Neon Snake Rush — Production Build & Publish Guide

A complete, monetization-ready Android game generated by the Game Factory pipeline.
The gameplay is your existing Neon Snake (menu, coin shop with upgrades, saved
progress); this build adds the full native money layer.

## Monetization wired in
- AdMob **banner** (adaptive, bottom of screen).
- AdMob **interstitial** on every 2nd game over.
- AdMob **rewarded** ad on "Watch Ad to Revive" (previously this was a fake timer —
  it now shows a real rewarded ad and only revives if the reward is earned).
- **Remove Ads** one-time in-app purchase (product id `remove_ads`), restores across devices.
- GDPR/UMP consent before ads load.

Out of the box it uses Google's official TEST ad ids (safe). Swap in your real ids
in ONE file: `app/src/main/java/com/refaz/neonsnake/AdConfig.kt` (and the App ID in
`app/build.gradle.kts` → manifestPlaceholders["admobAppId"]).

## Build & run
Open the folder in Android Studio (free) and press Run, or:
```
./gradlew assembleDebug        # test APK
```

## The four things only you can do (need your Google login)
1. Google Play developer account — one-time $25 (https://play.google.com/console).
2. AdMob account + Banner/Interstitial/Rewarded units (https://admob.google.com).
3. Paste those ids into AdConfig.kt + build.gradle.kts, set USE_TEST_ADS=false.
4. Create the in-app product `remove_ads` in Play Console → Monetize → In-app products.

## Sign & build the release
```
./scripts/make_keystore.sh     # once — back up upload-keystore.jks + passwords forever
cp keystore.properties.EXAMPLE keystore.properties   # then fill in your passwords
./scripts/build_release.sh
```
Outputs: `app/build/outputs/bundle/release/app-release.aab` (upload to Play).

## Publish
Play Console → Create app → fill listing from store_assets/store_listing.md → upload
the .aab → add privacy policy URL (host store_assets/privacy_policy.md), Data safety,
content rating, ads = Yes → 2+ screenshots → submit.

## Honest note
Package id `com.refaz.neonsnake` is permanent once published — change it in
app/build.gradle.kts before first upload if you want a different one. Test ads pay
nothing; real income starts only after you plug in real AdMob ids. Revenue depends on
installs/engagement — the code is done, the marketing is on you.
