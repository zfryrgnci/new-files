# Quantum Ascent — Production Build & Publish Guide

A complete, monetization-ready Android game generated by the Game Factory pipeline.
Gameplay is your existing 12-level physics platformer (double-jump & dash unlocks,
cores/coins, saved progress). This build swaps the game's SIMULATED ads for real ones.

## Monetization wired in
- AdMob **banner** (adaptive, bottom).
- AdMob **interstitial** — replaces the fake "COMMERCIAL BREAK" screen; fires on the
  same every-2-levels cadence the game already had.
- AdMob **rewarded** — the "Watch Ad: Restore" revive now shows a real rewarded ad and
  only restores if the reward is earned (was a fake 1s timer).
- **Remove Ads** one-time IAP (product id `remove_ads`), restores across devices.
- GDPR/UMP consent before ads load.

Ships with Google TEST ad ids. Swap real ids in ONE file:
`app/src/main/java/com/refaz/quantumascent/AdConfig.kt` (+ App ID in app/build.gradle.kts).

## Build / sign / publish
Same steps as the other titles:
1. Open in Android Studio → Run, or `./gradlew assembleDebug`.
2. Get a Play account ($25) + AdMob units; paste ids into AdConfig.kt; set USE_TEST_ADS=false.
3. Create the `remove_ads` in-app product in Play Console.
4. `./scripts/make_keystore.sh` → fill keystore.properties → `./scripts/build_release.sh`.
5. Upload `app/build/outputs/bundle/release/app-release.aab`; add privacy policy URL,
   screenshots, listing from store_assets/store_listing.md.

Package id `com.refaz.quantumascent` is permanent once published. Test ads pay nothing;
real income needs real ids + installs.
